Qué debe decidir el script

  1. Publicar solo valorizaciones activas de AVT con año 2020 o superior, marca, modelo, precio, moneda y fecha de cálculo válidos.
  2. El feed mockea actividad: “Un usuario acaba de valorizar un [marca + modelo + año]”, usando el valor referencial de AVT.
  3. La unicidad diaria es marca + modelo. El año no cuenta.
  4. La lista de marca + modelo usados se limpia a las 00:00:00.
  5. Si el servicio se detiene, omite horarios vencidos y continúa con el siguiente horario futuro.

Filtro de marcas

  1. Se permiten marcas regulares. El máximo nivel premium permitido es Lexus, Audi, BMW y Ford.
  2. Se excluyen: Aston Martin, Bentley, Bugatti, Ferrari, Lamborghini, Maserati, Maybach, McLaren, Porsche y Rolls-Royce.

Las marcas premium no aprobadas expresamente quedan fuera hasta una nueva decisión de negocio.
