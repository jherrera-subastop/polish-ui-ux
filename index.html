Reglas de publicación AVT

Horario y reglas del script · zona horaria: America/Lima

Horario diurno08:00:00–23:59:59↻ LOOP3 → 2 → 5 → 4 → 7 → 12 minEl loop inicia nuevamente a las 08:00.
Horario nocturno00:00:00–07:59:59↻ LOOP34 → 21 minEl loop inicia nuevamente a las 00:00.

Qué debe decidir el script

  1. Publicar solo valorizaciones activas de AVT con año 2020 o superior, marca, modelo, precio, moneda y fecha de cálculo válidos.
  2. El feed mockea actividad de usuarios: “Un usuario acaba de valorizar un [marca + modelo + año]”, usando el valor referencial que entrega AVT.
  3. La unicidad diaria es marca + modelo. El año no cuenta: si salió Toyota Yaris 2021, no puede salir otro Toyota Yaris ese día.
  4. La lista de marca + modelo usados se limpia a las 00:00:00. El horario no depende del inventario y nunca se repite un modelo solo para llenar un espacio.
  5. Si el servicio se detiene, no publica una ráfaga de pendientes: omite los horarios vencidos y continúa con el siguiente horario futuro.

  1. Cada marca + modelo pertenece a un único grupo. Puede aparecer en ambos días de su grupo, pero nunca dos veces en el mismo día.

Filtro de marcas

  1. Se permiten marcas regulares. El máximo nivel premium permitido es Lexus, Audi, BMW y Ford.
  2. Se excluyen marcas de alto lujo: Aston Martin, Bentley, Bugatti, Ferrari, Lamborghini, Maserati, Maybach, McLaren, Porsche y Rolls-Royce.

Las marcas premium no aprobadas expresamente quedan fuera hasta una nueva decisión de negocio.
