# Polish UI UX — VMC Ahora

Standalone, static reference for the VMC valuation feed. This repository contains the exact prebuilt version of the review UI published at:

https://vmc-valorization-exact.vercel.app

It includes the simulated feed, the `¡Valoriza aquí!` call to action, the simulation control, and the publication rules for the AVT script. The source reference in the original product repository is the `/solo` route.
